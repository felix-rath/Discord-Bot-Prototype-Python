# Pokemon Discord Bot Prototype

Dieses Repository enthält einen Prototyp eines Discord-Bots, der mit Python entwickelt wird.

## Über das Projekt

Der Bot wird entwickelt, um Web-Automatisierung, Datenverarbeitung und Discord-Integration miteinander zu verbinden.

Das Projekt nutzt Playwright, um Informationen aus Webseiten automatisiert auszulesen und diese über Discord verfügbar zu machen.

## Technologien

- Python
- Discord.py
- Playwright
- Web Scraping
- Async Programming
- JSON Data Storage

## Funktionen

### Web Automation

- Automatisiertes Öffnen und Auslesen von Webseiten mit Playwright
- Verarbeitung von ausgelesenen Informationen
- Automatisierte Abläufe zur Datenerfassung

### Discord Integration

- Verbindung mit einem Discord-Bot
- Verarbeitung von Discord-Befehlen
- Ausgabe von Informationen über Discord
- Automatisierte Benachrichtigungen

### Economy System

- Speicherung von Benutzerkonten über Discord-IDs
- Persistentes Speichern von Guthaben mit JSON
- Abrufen des aktuellen Kontostands
- Verwaltung von Benutzer-Geldständen

### Gambling System

- Einfaches Glücksspiel-System über Discord-Befehle
- Zufällige Gewinne und Verluste
- Automatische Aktualisierung des Kontostands
- Anzeige von Gewinn/Verlust und aktuellem Guthaben
